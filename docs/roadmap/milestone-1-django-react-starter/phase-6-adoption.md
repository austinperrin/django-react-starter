# Phase 6: Verify Adoption

[Docs](../../README.md) > [Roadmap](../README.md) > [Milestone 1](README.md) > Phase 6

## Goal and Prerequisites

**Goal:** A clean copy of this starter becomes an independent project through
the documented initialization flow and runs its own checks.

**Prerequisites:** [Phase 5](phase-5-integration.md) completes the integrated
checks and runbooks.

## Development Checklist

- [ ] Adapt the initialization runbook and helper to replace starter identity,
  contacts, and example UI/API material with project-owned content.
- [ ] Collapse starter-specific roadmap history into the new project's starting
  baseline while preserving reusable standards, decisions, and runbooks.
- [ ] Test the cleanup preview, apply, rollback, and refusal cases in a copy.
- [ ] Record which GitHub controls must be activated in each new repository.

## Review Checklist

- [ ] Start from a clean template copy with a distinct remote and identity.
- [ ] Follow the runbook as an adopter, then run local and hosted checks.
- [ ] Search active files for starter-only identity and broken links.

## Exit Criteria

- [ ] The adopted copy reads as its own project and starts both applications.
- [ ] The new project's checks pass and remaining project choices are explicit.
