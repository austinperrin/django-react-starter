# Phase 3: Build the Backend Baseline

[Docs](../../README.md) > [Roadmap](../README.md) > [Milestone 1](README.md) > Phase 3

## Goal and Prerequisites

**Goal:** A minimal Django REST Framework backend runs locally and has
repeatable backend checks.

**Prerequisites:** [Phase 2](phase-2-stack-decisions.md) approves runtime,
dependency, database, and local configuration choices.

## Development Checklist

- [ ] Add the Django project, package metadata, resolved dependencies, and a
  narrow API endpoint that proves the backend is running.
- [ ] Add local setup and migration commands without introducing product models.
- [ ] Add backend tests and quality checks for the delivered endpoint and setup.
- [ ] Document backend structure and local operations in their canonical pages.

## Review Checklist

- [ ] Verify a clean backend install, migration, start, and test run.
- [ ] Check that runtime configuration matches the approved secrets decision.
- [ ] Review package update coverage and license/security findings.

## Exit Criteria

- [ ] The API responds locally and backend checks pass from a clean checkout.
- [ ] No source-specific domain behavior is required to use the starter.
