# Phase 4: Build the Frontend Baseline

[Docs](../../README.md) > [Roadmap](../README.md) > [Milestone 1](README.md) > Phase 4

## Goal and Prerequisites

**Goal:** A React/Vite TypeScript frontend builds and can reach the local API.

**Prerequisites:** [Phase 3](phase-3-backend.md) provides the API boundary.

## Development Checklist

- [ ] Add the React/Vite application, package manifest, committed lockfile,
  and a minimal replaceable starter view.
- [ ] Configure local API access according to the approved architecture.
- [ ] Add focused frontend tests, type checks, linting, and build verification.
- [ ] Document frontend structure and development commands.

## Review Checklist

- [ ] Verify clean install, development start, tests, type checks, and build.
- [ ] Verify the frontend reaches the backend without production-only settings.
- [ ] Check dependency and generated-file treatment against repository standards.

## Exit Criteria

- [ ] The local application displays data from the starter API.
- [ ] Frontend checks pass from a clean checkout.
